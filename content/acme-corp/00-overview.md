# Acme Corp — Senior Frontend Engineer

This is example content that ships with interview-prep-kit so a fresh clone
has something to look at immediately. It corresponds to the "Acme Corp" entry
in `data/jobs.example.json`.

Replace this with your own study guide — either by hand, or by asking Claude
Code to run the `build-study-guide` skill once you've added a real
application with `add-application`.
