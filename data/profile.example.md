# Profile

This file is optional. If present, the `build-study-guide` skill reads it to
personalize generated lesson content — tone, analogies, and which topics need
more or less depth. Copy this file to `profile.md` (gitignored) and fill it in
with your own background. Delete any section that doesn't apply.

## Background

- Years of experience and primary role (e.g. "6 years, mostly backend Python").
- Degree / how you learned to code, if relevant to how material should be framed
  (e.g. "self-taught, no CS degree — prefer real-world analogies over academic
  terminology").
- Industries or domains you've worked in.

## Strengths

What you're confident about — the skill should spend less time here.

## Gaps

What you want to shore up before interviews — the skill should prioritize this.
Be specific (e.g. "shaky on Big-O analysis", "never done a system design
interview", "rusty on SQL joins").

## Learning style

How you learn best (e.g. "visual — diagrams and worked examples over prose",
"like day-by-day study schedules with one clear priority per day").

## Behavioral-interview material

A few real Situation/Decision/Trade-offs/Outcome stories from your own work,
if you have them ready — the skill can build behavioral-prep lessons around
these instead of generic advice.
